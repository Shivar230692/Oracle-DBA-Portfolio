\# Oracle SQL Basics



\## Overview



This project demonstrates common Oracle database objects and

basic SQL operations used by an Oracle DBA.



\## Topics Covered



\- Creating tables

\- Primary keys

\- Inserting data

\- Transactions and COMMIT

\- SELECT queries

\- Creating indexes

\- Creating views

\- Oracle data dictionary views

\- Database object status

\- Table metadata



\## Database Objects



\### EMPLOYEES



Sample employee table used to demonstrate basic SQL operations.



\### IDX\_EMPLOYEES\_DEPARTMENT



Index created on the department column to demonstrate indexing.



\### EMPLOYEE\_SUMMARY



View created to provide a simplified representation of employee data.



\## Oracle Data Dictionary



The script uses:



\- USER\_OBJECTS

\- USER\_TABLES



These views help DBAs inspect database objects and metadata.



\## Files



| File | Description | `basic\_database\_objects.sql` | SQL script demonstrating Oracle database objects |



\## Learning Objectives



After completing this project, the following Oracle concepts

should be understood:



1\. How to create a table.

2\. How to define a primary key.

3\. How to insert and commit data.

4\. How to create an index.

5\. How to create a view.

6\. How to inspect database objects.

7\. How to query Oracle data dictionary views.
