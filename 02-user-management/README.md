# Oracle User Management & Security

## Overview

This project demonstrates Oracle Database user administration, privilege management, role-based access control, tablespace quota monitoring, and security profile auditing.

The objective is to demonstrate practical Oracle DBA skills related to:

- User account administration
- Account status monitoring
- System privilege auditing
- Object privilege auditing
- Role management
- Tablespace quota monitoring
- Password and resource profile auditing
- Database security reviews

The SQL scripts in this project primarily use Oracle data dictionary views to inspect database security configuration and access controls.

---

## DBA Skills Demonstrated

- Oracle user and account administration
- User account status monitoring
- System privilege analysis
- Object-level privilege analysis
- Role-based access control (RBAC)
- Security privilege auditing
- Tablespace quota monitoring
- Password policy analysis
- Oracle profile management concepts
- Data dictionary querying
- Security and access reviews
